Kebijakan Privasi Andi Arama

Berlaku sejak 5 November 2026.

Data yang diakses

Andi Arama mengakses data Google pengguna melalui YouTube Data API dan YouTube Analytics API, hanya untuk channel YouTube milik Arama yang pemiliknya memberi izin secara langsung:

  • Informasi channel (nama, ID, jumlah subscriber dan video).
  • Video yang diunggah, beserta judul, deskripsi, tag, thumbnail, dan status privasinya.
  • Statistik dan laporan analitik channel.

Cara data dipakai

  • Mengunggah video dan mengatur metadata video di channel milik Arama.
  • Membaca statistik untuk mengevaluasi performa video milik Arama.

Data tidak dipakai untuk iklan, tidak dijual, dan tidak dibagikan ke pihak ketiga.

Penyimpanan

Token akses disimpan di server milik Arama dalam file yang hanya bisa dibaca oleh aplikasi ini. Data statistik hanya disimpan untuk laporan internal. Penggunaan data Google mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses

Pemilik akun dapat mencabut akses kapan saja di https://myaccount.google.com/permissions. Setelah dicabut, token yang tersimpan akan dihapus.

Summary: Andi Arama accesses YouTube data only for Arama's own channels, only to upload videos, manage their metadata, and read analytics. Data is not sold, not used for advertising, and not shared with third parties. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
